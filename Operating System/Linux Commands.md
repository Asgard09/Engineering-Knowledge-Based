# 1. Navigation and Directory Listing
|**Command**|**What It Does**|
|---|---|
|`pwd`|Print current working directory path|
|`ls -la`|List all files/folders including hidden ones (`.`) with permissions and sizes|
|`cd /path/to/folder`|Change directory to target path|
|`cd ~`|Jump directly to user's home directory|
|`cd ..`|Move up one directory level|
# 2. File and Folder Management
|**Command**|**What It Does**|
|---|---|
|`mkdir -p folder/subfolder`|Create directory structure (creates parent folders if needed)|
|`touch file.txt`|Create an empty file or update timestamp|
|`cp source.txt dest.txt`|Copy a file|
|`cp -r dir1 dir2`|Copy a folder recursively|
|`mv old_name.txt new_name.txt`|Move or rename a file/folder|
|`rm file.txt`|Remove a single file|
|`rm -rf folder_name`|Permanently delete a folder and all its contents|
