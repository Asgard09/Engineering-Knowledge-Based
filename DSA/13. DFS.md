# Template
```python
def fn(graph):
    def dfs(node):
        ans = 0
        # TODO: logic
        for neighbor in graph[node]:
            if neighbor not in seen:
                seen.add(neighbor)
                ans += dfs(neighbor)

        return ans

    seen = {START_NODE}

    return dfs(START_NODE)
```
# Choose between return value or don’t 
- Use `dfs() -> None` when the child result doesn’t affect the parent. Example in Connected Components: we don’t care how the child work, we just need to know after all the `visited` is full of verticals
- Use `dfs() -> bool, int` when we need the report of child to determine the final result. Example Find Eventual Safe States, we need to know if the children is in the cycle to determine the parent is safe or unsafe
# Direct Graph
- Notice about cycle, can’t use the seen for controlling states
# Top-down
Pass information from the node to the neighbor, the neighbor depend on the node, include:
- Except start node, we also pass the parent states as a parameter
# Bottom-up
Instead of passing data down, we calculate values at each level based on the values from lower levels, the node depend on the neighbor, include:
- have the if in the start of dfs()
- Have the return of dfs(), usually the boolean True/False
