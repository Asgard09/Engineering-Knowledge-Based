# Template
When we add new item in the queue, need to add this in visited for avoiding duplicate variable in queue, and we can process this node again and again, `deque([3,3])`
```python
from collections import deque

def fn(graph):
    que = deque([START_NODE])
    seen = {START_NODE}
    ans = 0

    while que:
        node = que.popleft()
        # TODO: logic
        for neighbor in graph[node]:
            if neighbor not in seen:
                seen.add(neighbor)
                que.append(neighbor)

    return ans

```

# Traversal in Grid
```python
def shortestPathBinaryMatrix(self, grid: list[list[int]]) -> int:
       rows = len(grid)
       cols = len(grid[0])
       if grid[0][0] == 1 or grid[rows-1][cols-1] == 1:
           return -1

       visited = set([(0,0)])
       queue = deque([[0,0,1]])

       directions = [
            (0, 1), (0, -1), (1, 0), (-1, 0),  # 4 directions
            (1, 1), (1, -1), (-1, 1), (-1, -1)  # 8 directons
        ]

        while queue:
            cell = queue.popleft()
            r, c, dist = cell[0], cell[1], cell[2]
  
            if r == rows - 1 and c == cols - 1:
                return dist

            for d in directions:
                nr = r + d[0]
                nc = c + d[1]

                if 0 <= nr < rows and 0 <= nc < cols and (nr, nc) not in visited and grid[nr][nc] == 0:
                    queue.append([nr, nc, dist+1])
                    visited.add((nr, nc))
        return -1
```
# Identify the anchors
This is the element that bfs start, and they must be known the result in first, example:
- 01 Matrix: The anchor is the 0 because the distance from it to nearest 0 is always 0
- Surrounded Regions: The anchor is the ‘O’ in the boundary, we know this is the safety regions in the first
# Multi Traversal and Single Traversal
- Single Traversal: we need to satisfy 1 condition –> use one anchor
- Multiple Traversal: we need to satisfy multiple conditions –> for each condition is the specific anchor the result now will be the combination of the res for these traversals
