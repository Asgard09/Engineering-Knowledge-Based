# 1. OSI Models
The OSI Model is conceptual framework describe how data is transmitted between devices over a network. It divides into seven layers.
1. Physical Layer: Transmitting raw bits over physical medium, such as cable or wireless signal
2. Data Link Layer: Manage MAC address, framing and error detection
3. Network Layer: Routing packages between different network
4. Transport Layer: Ensuring reliable data and error recovery. Common protocol are TCP and UDP
5. Session Layer: Manage communication session between application
6. Presentation Layer: Translate data format, performs decryption and encryption 
7. Application Layer: Provides network services to application through protocols such as HTTP, HTTPs
